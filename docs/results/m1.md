## Analyze

- **Most bugs are narrow.** 11 of the 20 bugs change exactly one of 74 spec rows. A suite that lacks
  that one case passes, whatever its line coverage; this is the gap M2's property and mutation
  testing is meant to measure.
- **Finding a floating-point witness was hard.** Python's `round` on a float is already half-even,
  and most decimal factors times a whole number are exact in binary. A search over 7,992 products
  (8 amounts x 999 factors) found 2 where the float result differs from exact half-even:
  100 x 0.545 and 100 x 0.575. Row m12 uses the first.
- **A seeded bug can hang the code under test.** The first version of S5 made the December piece end
  on December 31, so the loop never advanced past it and the evaluator ran until it was killed. The
  harness now treats a timeout as a changed answer, and S5 was replaced by a terminating off-by-one.
- **Time-zone bugs depend on the machine.** S3 (using the machine's zone) is invisible on a machine
  set to America/New_York. Its witness fails both here (UTC+7) and on CI runners (UTC).

## Improve and Control

- CI runs lint, types and the spec in all three languages, the seeded-bug harness (it fails the job
  unless every bug is live and clean code passes every row, and prints the RESULT line as a
  `::notice`), and the three audits.
- `test_bug_catalog.py` fails as soon as a code change breaks a bug's find text.
